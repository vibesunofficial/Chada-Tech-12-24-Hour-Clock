# Chada-Tech-12-24-Hour-Clock
In this assignment the goal was to make a clock that displayed 12-hour and 24-hour formats that could be edited. It would ask the user to enter the hours, minutes, and seconds, then display both of the times in their respective formats with the ability to add any number of hours, minutes, or seconds. The best thing I did on this assignment was the code to convert the input into the separate times. The one place I would enhance my code would be the input screen. Right now it works fine, but when you enter something that doesn't have the value of an integer the program starts to freak out. The way I fixed this was to abort the program, which is probably not the most effective way to handle it. In the coding itself I sectioned off all the working pieces and left comments for each of them. This is so that people could go through it and see what each part of the program does.
